T5.2 的精确口径（`src/platform/dsh/audit.ts:94-98`）：

```
denied    ← reasonCode 含 "denied" 或 == "user_cancelled"
confirmed ← reasonCode == "user_approved" 或 == "completed"
allowed   ← 其余一切
```

核对脚本（只读）：

```sh
python3 -c "
import json,collections
lines=[l for l in open('/Users/clkj/.dsh/at-terminal/agent-audit.jsonl') if l.strip()][-50:]
c=collections.Counter()
for l in lines:
    rc=json.loads(l).get('reasonCode','')
    c['denied' if ('denied' in rc or rc=='user_cancelled') else ('confirmed' if rc in ('user_approved','completed') else 'allowed')]+=1
print(c)
"
```

## 5. at-pc 驱动注意（2026-10-23 实跑踩过的坑）

1. **点审批卡前必须让窗口成为 key window**：DSH 不在前台时合成点击会被当成「激活窗口」吞掉，卡片停在「等待审批」直到 60 s 超时。判据 = 窗口左上角三个红绿灯是**灰的**。做法：`osascript -e 'tell application "DeepSeek Harness" to activate'`，再把「点击 + 打字 + 回车」放进**一次** `batch_actions`。
2. **坐标现拍现用**：右侧栏开/关会让聊天列宽在 1280 与 ~820 物理像素之间跳，同一张卡的按钮 x 会差 ~250 px。拿几秒前的截图坐标去点就是点空。
3. **审批超时 60 s**（`confirmation_timeout`，`durationMs≈60000`），留给操作者的窗口只有一分钟。卡住了就点「拒绝」，composer 立刻恢复。
4. **鼠标吃逻辑点，截图/OCR 是物理像素**：Retina 下要 ÷`scale_factor`；传错时事件投到屏外且**静默返回 `success:true`**。
5. **HUD 窗口位置每轮都可能变**：拖拽测试前先 `capture_screen crop` 校准，别用上一轮的坐标。

## 6. 已知限制（**不要当 bug 报**）

| 现象 | 为什么 |
