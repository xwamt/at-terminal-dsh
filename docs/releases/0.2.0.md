# AT Terminal (DSH) 0.2.0 Release Notes

## Summary

Version 0.2.0 makes the floating monitor the primary way to watch a connection, makes the
direct tools honest and bounded, and stops imposing Windows keyboard habits on macOS. Long
commands and container mount paths are clipped instead of widening the panel.

## Highlights

- **Capsule-first monitor**: connecting opens the floating window as a capsule (CPU / memory
  chips) and a fresh connection expands into Overview / Hardware / Agent execution on demand.
- **Per-connection audit history**: the Agent tab shows the four most recent rows; **History**
  reveals everything the current connection recorded and resets on disconnect.
- **Platform-native shortcuts**: `⌘C` / `⌘V` / `⌘F` on macOS, `Ctrl+C` / `Ctrl+V` / `Ctrl+F`
  elsewhere. On macOS `Ctrl+C` remains the shell interrupt.
- **Stricter direct tools**: 15 tools with argument validation, honest capabilities, a correct
  SFTP mtime and bounded hardware metrics.

## Added

- Monitor HUD surface with Overview, Hardware and Agent execution tabs, draggable by its header
  and collapsible back to the capsule.
- Audit history accumulated per connection: polls ask the host for the retained window (50
  rows), merge new entries by id, stamp the connection start time so stale rows are excluded,
  and clear everything on disconnect.
- `History` / `Back to recent` control on the audit card (shown once a connection has more than
  four rows), with the current connection's record count.
- Shared platform helper (`webview/terminal/platform.ts`): `isMacPlatform()` plus
  `primaryModifierLabel()`, used by the terminal clipboard handler, the find-bar shortcut and
  the search tooltip.
- `diskMounts` in `at_terminal_get_hardware_metrics` output (filesystem, mount point, total and
  used bytes, use percent).
- Tool argument validation for every direct tool: missing or blank `path` / `command` / `content`
  / `newPath` / `target` now produce a message that names the tool and the field.
- Collapsible command cells in the audit table and collapsible mount labels in the disk card,
  driven by one shared disclosure rule (`needsTextDisclosure`).

## Fixed / Improved

- `at_terminal_sftp_stat_path` rendered `modifiedAt` as 1970: the SFTP `mtime` is in seconds and
  was formatted as if it were milliseconds. It now renders the real instant and shows `unknown`
  for a missing value.
- `at_terminal_ping` advertised only three capabilities although SFTP, remote commands, hardware
  metrics and agent status all worked; the probe now reports what the build ships.
- Missing tool arguments surfaced as `Cannot read properties of undefined (reading 'trim')`;
  validation now runs before any service call.
- Hardware metrics were a single `CPU x%, Mem y / z` line despite the tool promising disk,
  network and processes; the render now reports load, memory, network, disk mounts and top
  processes, with Docker overlay/tmpfs mounts filtered out and each section capped at five rows
  plus a `(+N more)` count.
- The HUD reopened expanded after any earlier `open()` because `forceExpanded` outlived a
  disconnect; a new connection now always starts as the capsule and resets the subtab and
  history.
- The overview page duplicated the tab strip as a row of hardware / agent / minimize buttons;
  the duplicate row is gone.
- Long audit commands widened the table past the floating window (no ellipsis, horizontal
  dragging). The table now uses a fixed layout with a clipped command cell and a disclosure
  chevron; the decision badge no longer breaks into stacked characters.
- Long disk mount paths pushed the usage figure out of the card; the label now ellipsizes with
  its own disclosure and the usage column never shrinks.
- The terminal considered only `Control` for copy/paste and accepted either `Control` or
  `Command` for find. Copy/paste/find now follow the operating system, and `Cmd+V` rides the
  native paste event so no clipboard-read permission is needed.
- The find-bar tooltip was hard-coded to `Ctrl/⌘+F`; it now renders the platform's own modifier.
- The asset row's keydown handler typed `currentTarget` as `unknown`, which was the only
  remaining `tsc` error in the tree; the row menu anchor type is now explicit.

## Upgrading

- `link:` installs (this machine): rebuild, then restart DeepSeek Harness so the host half
  reloads `dsh/tools.js`; a page refresh is enough for the client bundle.
- Other machines: install the tarball, or unpack it over the bundle directory. The tarball does
  not include `ssh2` (resolved from the repository's `node_modules` at runtime) or the
  build/verify scripts under `dsh/scripts/`.
