# AT Terminal (DSH) 0.3.3 Release Notes

## Summary

Version 0.3.3 is the **DeepSeek Harness 0.2.2-rc.5 compatibility, concurrency and
reliability** release. It closes the runtime-contract gaps found in a full repository review
against the installed Harness and delivers the five workstreams that review identified:

- **monitor fallback to the local Host** when no SSH server is connected, with real
  macOS / Windows / Linux readers instead of placeholder numbers;
- **parallel scheduling for stateless read tools** and **per-action tracking for concurrent
  Agent / SubAgent work**;
- **recursive multi-hop jump hosts** with cycle detection and safe reverse-order teardown;
- **hardened persistent SSH terminals** — SubAgent refusal, a per-Agent session cap,
  `terminal_open({ cwd })`, and DSH 0.2.2's `readOutput()` / boolean `cancel()` contract;
- **long-running reliability**: permanent `ssh2` error guards, 5 MiB audit-log rotation with an
  in-memory fast path, coalesced metric probes, and honest progress/metrics reporting.

Both packages ship in lockstep at `0.3.3`: the main plugin
(`@at-series/dsh-at-terminal`) and the optional composition bundle
(`@at-series/dsh-at-terminal-ssh`). The bundle resolves the plugin's SSH backend by subpath, so
publishing one without the other is not a release.

The 13 commits since `v0.3.2` touch 52 files (+3,717 / −479), before this release's version and
documentation updates.

## Highlights

### DSH 0.2.2-rc.5 compatibility

- `verify:dsh` now runs against DeepSeek Harness Desktop **0.2.2-rc.5**: 19 tools are checked
  against the installed `dsh-tools`, the 9 settings fields against the installed
  `schemastery`, and the client factory against the real bundle contract.
- The opt-in terminal backend implements DSH 0.2.2's `TerminalSendOperation` contract:
  `readOutput()` returns only the unread delta (from a second bounded mirror, so the final
  `viewport` stays complete) and `cancel()` returns `true` on the first call, `false` after.
  Verify check 12 now builds a real send operation out of `terminal.bundle.js` and exercises
  both methods instead of a text scan.
- Guard denials return the structured `{ reason, info: { name: 'AtTerminalPolicyError', code } }`
  shape. `dsh/index.js` reads `ToolErrorInfo.code` into the audit row, so a sensitive-path
  refusal is recorded as `sensitive_path_denied` and an unclassified tool as
  `unclassified_tool_denied`, not as a generic `runtime_error`.
- Background-job prompt guidance now says to call `job_output` only when incremental output is
  needed (or the completion notice omitted it), matching the host's job semantics.

### Concurrency and multi-Agent visibility

- **Seven stateless read tools** — `at_terminal_ping`, `at_terminal_list_ssh_servers`,
  `at_terminal_get_terminal_context`, `at_terminal_sftp_list_directory`,
  `at_terminal_sftp_stat_path`, `at_terminal_sftp_read_file` and
  `at_terminal_get_hardware_metrics` — declare `isConcurrencySafe: () => true`; the matching
  `dsh/policy.js` rows carry `parallel: true`. Every write and command tool stays exclusive.
- **`AgentExecutionBridge` now tracks every action in a map keyed by `actionId`** instead of a
  single `currentAction`. `getSnapshot()` exposes an `activeActions` array with each action's
  `agentId` / `sessionId` when available; `currentAction` remains a compatibility projection of
  the newest live action, and a settled action stays visible for three seconds.
- **Metric probes are coalesced per server**: overlapping HUD, sidebar and Agent polls share
  one in-flight probe instead of racing each other's CPU/network samples and reporting 0%.
  The local Host collector applies the same rule.

### Connections and persistent terminals

- **Recursive multi-hop jump hosts**: a jump host may itself declare a `jumpHostId`, so
  `local → bastion A → bastion B → target` builds one tunnel per hop instead of flattening the
  chain. Chains are capped at five hops, a cycle fails with the full path
  (`Jump host cycle detected: a -> b -> a`), and disposal closes the nearest client before
  releasing the upstream tunnel it rides on.
- **`ssh2` late fatal errors are contained**: `SftpSession` and `SshConnectionTester` install a
  permanent no-op `error` listener, so a second `Connection lost before handshake` emitted
  after `client.end()` can no longer escape as an uncaught EventEmitter exception and kill the
  Host process. `SshConnectionTester.cleanup()` now removes only its own `once` handlers.
- **Persistent SSH terminal admission**: an agent-opened shell follows the background-connection
  rule — the server must allow background connections or already have a terminal tab open in
  the AT Terminal panel. SubAgents are refused (the user cannot see their terminals); one Agent
  may hold at most four live sessions, and closing a session releases its slot immediately.
- **`terminal_open({ cwd })` works over SSH**: the backend runs `cd -- <single-quoted path>` as
  the first command, so the shell starts where the caller asked and paths with spaces or quotes
  survive.

### Monitor, metrics and audit storage

- **Local Host metrics**: with no SSH server connected, the monitor reads the Host machine —
  `vm_stat` / `netstat` / `df` on macOS, PowerShell CIM on Windows, `/proc` on Linux — and
  labels the target `Local machine · <platform>` (中文「本机 · 平台」).
- **No fabricated readings**: the remote collector no longer invents 8 GiB memory / 4 GiB free
  or a 50 GiB `/dev/root` disk when a probe returns nothing. Real block devices under `/mnt`,
  `/opt`, `/srv` and `/var` are now recognised, and mounts with spaces parse correctly.
- **Audit log rotation and fast path**: `agent-audit.jsonl` rotates to `.1` before an append
  once it reaches **5 MiB** (check and append share the serialized write tail). The first
  `readRecent()` hydrates a 50-line in-memory ring; later small HUD polls are answered from the
  ring instead of re-reading the whole growing JSONL.
- **Concurrent-action UI**: the Agent tab renders every live action (with its `agentId`) rather
  than only the newest, and the local-machine view is always available in the target selector.
- **Honest SFTP read progress**: `sftpReadFile` starts its transfer row at `0%` / `0 B/s`
  instead of a fabricated `30%` / `50 KiB/s`; the row is completed when the buffered read
  returns.

## Added

- `LocalHardwareMetricsCollector` — native local Host metrics for macOS, Windows and Linux.
- Recursive `jumpHostId` chains (maximum five hops) with cycle detection.
- Persistent-terminal admission policy: SubAgent refusal, per-owner session cap (4), initial
  `cwd`.
- `TerminalSendOperation.readOutput()` and boolean `cancel()`.
- Structured policy-denial `info.code` values (`sensitive_path_denied`,
  `unclassified_tool_denied`) and their audit reason mapping.
- `isConcurrencySafe` on seven stateless read tools and `parallel: true` in `dsh/policy.js`.
- `activeActions` in `AgentExecutionSnapshot`, with `agentId` / `sessionId` per action.
- 5 MiB audit-log rotation and an in-memory ring fast path for `readRecent()`.

## Changed / Improved

- The monitor falls back to local Host metrics and labels the target explicitly instead of
  showing an empty capsule or the last disconnected server. The capsule can be dragged from its
  six-dot grip or any non-button chrome; CPU / memory / expand / close stay click targets.
- Concurrent metric probes share one in-flight request per server (remote and local).
- Disk parsing accepts real devices under `/mnt`, `/opt`, `/srv` and `/var`; pseudo filesystems
  stay excluded.
- Persistent SSH sessions now require the same admission as background connections and fail
  with actionable messages.
- The prompt's background-job guidance is shorter and matches DSH's `job_output` semantics.
- Verify check 12 exercises the compiled terminal bundle's send-operation behaviour rather than
  scanning source text.

## Fixed

- Late fatal `ssh2` errors during connect teardown no longer crash the DSH Host process.
- Two-level+ jump chains no longer silently drop the first bastion.
- A second concurrent remote command no longer overwrites the first in the execution monitor.
- Overlapping metric probes no longer report a false 0% CPU / 0 B/s.
- Failed metric probes no longer display invented memory or 50 GiB disk values.
- `sftpReadFile` no longer reports a fake 30% transfer progress.
- Policy refusals are recorded with their real reason code instead of `runtime_error`.
- A growing `agent-audit.jsonl` no longer makes every HUD poll re-read the whole file.

## Upgrading

- `link:` installs (this machine): `npm run build`, then restart DeepSeek Harness so the Host
  half reloads `dsh/host.bundle.js`; a page refresh is enough for the client bundle.
- Other machines: install the tarball(s), or `npm install --save-exact @at-series/dsh-at-terminal`
  and optionally `@at-series/dsh-at-terminal-ssh`.
- The plugin tarball includes `README.md`; `ssh2` is resolved from the repository's
  `node_modules` at runtime, and the build/verify scripts under `dsh/scripts/` are not shipped.
