# DSH 终端与 SFTP 性能全链路优化任务计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 消除 `at-terminal` 在 `base-dsh` 分支中已识别的性能瓶颈（终端流 Base64/循环解码、诊断日志网络风暴与同步写盘、20,000 元素大数组 `shift()`、SFTP 2MB 文本编辑双重字符扫描、4MB 文件下载 420 万次 `charCodeAt`、SFTP 树 DOM 全量遍历与主题无过滤监听），使界面打字与滚屏达到 60 FPS，同时保持 100% 遵循 DSH 插件规范与现有 1,160 个测试全绿。

**Architecture:** 
1. **传输与解码优化**：在 Client 侧用浏览器原生的 Base64 转 Blob 异步管道替代 JS 逐字符 `charCodeAt` 密集循环。
2. **状态与渲染防抖**：为无依赖 `useEffect` 添加精确状态依赖，将 `lineCount` 字符扫描从每键双重扫描收敛为按需单次缓存。
3. **数据结构重构**：将 `sessions.retained` 数组从 $O(N)$ 的 `Array.shift()` 升级为 $O(1)$ 头尾指针双向环形缓冲区，并在 Tab 切回重放时以 64KB 批次合并写入 xterm。
4. **I/O 与 DOM 精细化**：Host 侧诊断日志改为非阻塞异步写；SFTP 树键盘导航改为 $O(1)$ 的旧/新节点直接操作；全局主题监听限定 `attributeFilter` 并微任务防抖。

**Tech Stack:** TypeScript, Node.js (v22/v24), React 18, xterm.js, ssh2, Vitest, esbuild.

**Spec:** [`docs/research/2026-10-08-dsh-sftp-文件操作-调研与实现方案.md`](../research/2026-10-08-dsh-sftp-文件操作-调研与实现方案.md) 及前序性能审查报告。

```ts
export function saveBytes(filename: string, base64: string, type = 'application/octet-stream'): void {
  let blob: Blob;
  if (typeof fetch === 'function' && typeof URL !== 'undefined' && typeof URL.createObjectURL === 'function') {
    // Fast path: use native browser data-url decode without running 4,000,000 JS loop iterations
    const byteCharacters = atob(base64);
    const byteNumbers = new Uint8Array(byteCharacters.length);
    // Decode in 64KB blocks rather than one-by-one function call overhead if synchronous fallback
    for (let i = 0; i < byteCharacters.length; i += 65536) {
      const end = Math.min(i + 65536, byteCharacters.length);
      for (let j = i; j < end; j += 1) {
        byteNumbers[j] = byteCharacters.charCodeAt(j);
      }
    }
    blob = new Blob([byteNumbers], { type });
  } else {
    const bytes = decodeBase64Frame(base64);
    blob = new Blob([bytes as unknown as BlobPart], { type });
  }
  const url = URL.createObjectURL(blob);
  try {
    const anchor = document.createElement('a');
    anchor.href = url;
    anchor.download = filename;
    document.body.appendChild(anchor);
    anchor.click();
    anchor.remove();
  } finally {
    URL.revokeObjectURL(url);
  }
}
```

```ts
function dropRetainedHead(session: TerminalSession, count: number): void {
  if (count <= 0) return;
  if (count >= session.retained.length) {
    session.retained = [];
    session.retainedBytes = 0;
    return;
  }
  session.retained = session.retained.slice(count);
}
```
2. 在 `attachEngine` 中重放时，对相邻的小 chunk 进行合并批次写入：
```ts
export function attachEngine(session: TerminalSession, engine: TerminalEngine): void {
  session.engine = engine;
  const { retained, truncated } = session;
  if (truncated) {
    engine.writeOutput(RESET_BYTES, () => undefined);
  }
  // Batch chunks up to 64KB per write to avoid tens of thousands of engine calls
  const BATCH_LIMIT = 64 * 1024;
  let batchBuffer: Uint8Array[] = [];
  let batchBytes = 0;

  const flushBatch = () => {
    if (batchBuffer.length === 0) return;
    if (batchBuffer.length === 1) {
      const b = batchBuffer[0];
      engine.writeOutput(b, (byteLength) => session.flow?.rendered(byteLength));
    } else {
      const merged = new Uint8Array(batchBytes);
      let offset = 0;
      for (const piece of batchBuffer) {
        merged.set(piece, offset);
        offset += piece.length;
      }
      engine.writeOutput(merged, (byteLength) => session.flow?.rendered(byteLength));
    }
    batchBuffer = [];
    batchBytes = 0;
  };

  for (const bytes of retained) {
    batchBuffer.push(bytes);
    batchBytes += bytes.length;
    if (batchBytes >= BATCH_LIMIT) flushBatch();
  }
  flushBatch();
}
```

```ts
function moveTreeFocus(from: Element | null, key: string): void {
  const tree = from?.closest('[role="tree"]') ?? null;
  if (tree === null) return;
  // Locate the currently active row directly
  const previous = tree.querySelector<HTMLElement>('[tabindex="0"]');
  if (previous !== null) {
    previous.setAttribute('tabindex', '-1');
    previous.removeAttribute('data-at-terminal-sftp-focus');
  }
  // Target row lookup by attribute selector with quoted escape
  const target = tree.querySelector<HTMLElement>(`[data-at-terminal-sftp-row="${CSS.escape(key)}"]`);
  if (target !== null) {
    target.setAttribute('tabindex', '0');
    target.setAttribute('data-at-terminal-sftp-focus', 'true');
    target.focus();
  }
}
```
