### Task S1: 为 `SftpSession` 与 `SshConnectionTester` 补齐常驻 Fatal Error 守护

**背景与根因：**
`ssh2` 的 `Client` 在握手未完成时断开（如跳板机闪断、超时调用 `client.end()`）或连接建立后底层 Socket 报错时，会在 `client.once('error', reject)` 被消费后再次触发 `'error'` 事件（`Connection lost before handshake`, `fatal: true`）。
- `src/sftp/SftpSession.ts:69-75` 目前仅挂载了 `client.once('error', reject)`，无常驻 `error` 监听器；
- `src/ssh/SshConnectionTester.ts:32-33` 在 `cleanup()` 中先调用 `client.removeAllListeners('error')`，紧接着调用 `client.end()`，导致 `end()` 同步或异步触发的 `'error'` 无监听器接管，Node `EventEmitter` 直接抛出未捕获异常杀死整个 DSH Host 进程。

**Files:**
- Modify: `src/sftp/SftpSession.ts:63-92`
- Modify: `src/ssh/SshConnectionTester.ts:19-36`
- Test: `test/ssh/SshFatalErrorGuard.test.ts`

**Interfaces:**
- `SftpSession.connect()` 必须在创建 `Client` 实例后立即挂载常驻 `client.on('error', () => undefined)`。
- `testSshConnection()` 必须在创建 `Client` 实例后挂载常驻 `client.on('error', () => undefined)`，且 `cleanup()` 中不得移除该常驻守护监听器（仅移除 `once('ready', resolveOnce)` 和 `once('error', rejectOnce)`）。

```ts
class SshSendOperation implements TerminalSendOperation {
  private readonly buffer = new BoundedScrollback(48 * 1024, 2000);
  private readonly unread = new BoundedScrollback(48 * 1024, 2000);
  private readonly deferred = createDeferred<TerminalSendOutcome>();
  private finished = false;
  private cancelled = false;

  constructor(private readonly onCancel: (reason: TerminalWaitReason, fromCancel: boolean) => void) {}

  get done(): Promise<TerminalSendOutcome> {
    return this.deferred.promise;
  }

  get settled(): boolean {
    return this.finished;
  }

  append(text: string): void {
    if (!this.finished) {
      this.buffer.append(text);
      this.unread.append(text);
    }
  }

  readOutput(): TerminalSendRead {
    const snap = this.unread.drain();
    return { delta: snap.text, truncated: snap.truncated };
  }

  consume(): { text: string; truncated: boolean } {
    const snapshot = this.buffer.snapshot();
    return { text: snapshot.text, truncated: snapshot.truncated };
  }

  resolve(outcome: TerminalSendOutcome): void {
    if (this.finished) return;
    this.finished = true;
    this.deferred.resolve(outcome);
  }

  reject(error: unknown): void {
    if (this.finished) return;
    this.finished = true;
    this.deferred.reject(error);
  }

  cancel(): boolean {
    if (this.finished || this.cancelled) return false;
    this.cancelled = true;
    this.onCancel('inferred_idle', true);
    return true;
  }
}
```

  drain(): { text: string; truncated: boolean } {
