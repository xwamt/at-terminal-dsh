## 1. 背景与目标

### 1.1 现状判断

AT Terminal 的 DSH 客户端功能面已经完整，上一轮也把主题桥、i18n、焦点管理、SFTP 树键盘模型做扎实了。但从「像 DSH 原生的一部分」看，仍有四类系统性差距：

1. **几何/表面仍是 VS Code webview 语言**：24px 控件、4–6px 圆角、白色面板底；DSH 侧栏行是 13px / 12px 圆角，按钮是 28px / 8px 圆角，栏体使用 `--dsw-specific-sidebar-fill`。
2. **图标资产未接线**：`client/icons/` 里 6 个按官方 16px 画板绘制的图标零 import；实际 UI 有 16 处 emoji 和 `▣ / · / ↪ / ▶ / ▼` 字符 glyph。
3. **窄栏与生命周期没有对齐**：服务器表单两列在默认右栏宽度下塌陷；资产页的 `useState` 在切 tab（body 卸载）时全部丢失。
4. **少量真实缺陷**：未定义 CSS 类、`.att-badge` 重名、`window.confirm` 与自定义弹窗混用、文件编辑器 dirty 关闭无确认、监控硬编码英文。

### 1.2 可验收的目标

| 目标         | 量化判据                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 窄栏可完成核心流程  | 380px 面板宽度下，新增/编辑服务器表单无横向溢出，字段可用；SFTP 工具栏不高于 2 行                         |
| 视觉与宿主同一套语言 | 所有面板控件使用宿主 token 几何；无字面色；无 4px 圆角按钮；无 emoji 图标                           |
| 不丢用户输入     | 切 tab 再回来，服务器表单草稿、选中行、折叠分组、SFTP 展开状态保留；密码与编辑器 buffer 不保留                 |
| 键盘 / 读屏可用  | 资产列表、分组、右键菜单、监控 tab、HUD 可纯键盘完成；焦点可见且归还                                   |
| 文案完整       | 中英 key 对称；监控/HUD 无硬编码英文；时间按宿主 locale 格式化                                 |
| 不破坏宿主契约    | `verify:dsh` 9/9、`verify:kernel` 按当前脚本输出全绿；不 import 客户端包；不改 `webview/**` |

### UI2-11 SFTP 展开/滚动恢复与脏关闭

- **优先级/估算**：P2 / M
- **目标**：切 tab 再回来，文件树保持用户展开的层级和阅读位置；关闭 dirty 编辑器有确认。

  - 项目明确不保留编辑器 buffer（`body-session.ts:248` 注释），这个判断正确，**不要改**。
- **接口**：`tabState.ts`（UI2-03 新建）；`sidebarRight` tab key。
- **实施步骤**：
  1. 用 `tabState` 持久化每个 session tab 的 `sftpExpanded`、`scrollTop`；挂载时恢复展开路径并重读（不要恢复 `sftpChildren` 缓存，避免过期）。
  2. 滚动容器加 ref；`scroll` 事件写回；`visible` 变 true 时恢复。
  3. dirty 关闭确认复用 UI2-04 的 `ConfirmDialog`；保存成功后关闭不弹。
  4. 不做：跨 tab 恢复编辑器 buffer；不做自动保存。
- **DoD**：
  - 展开 `/root/docker` → 切到终端 → 切回文件，`/root/docker` 仍展开且滚动位置一致；
  - 重读失败时显示该层失败行，不崩溃；

- **测试/验证**：`client-bundle.test.ts` 重挂载用例；SFTP 读取失败用例。
- **风险/回滚**：恢复展开可能触发多次读；用现有 pending 行与去重逻辑；失败不阻塞其他层。

### UI2-12 `tool.call.toolview`：远程命令工具卡

- **优先级/估算**：P2 / L
- **目标**：对话中的 `at_terminal_run_remote_command` 不再是一段压平 JSON，而是一张可折叠的终端卡。
- **现状证据**：
  - `dsh/tools.js:305` 起的结果已含 `serverLabel/host/command/exitCode/stdout/stderr/durationMs/timedOut/truncated`；
  - 目前客户端没有注册 `tool.call.toolview`，走通用卡片。
- **接口**：keyed slot `tool.call.toolview`（wire tool name）；`ToolCallOwnerProps` 的 `phase/block/callId`；不 import primitives。
- **实施步骤**：
  1. 新建 `client/views/toolCall.ts`：
     - `preparing`：单行 skeleton（图标 + 「准备执行」）；
     - `result`：优先读 block 的结构化 result content；只有文本时尝试 `JSON.parse`；失败则渲染与通用行相似的 fallback（不要抛错）；
     - 折叠行：服务器 + `$ command` + 状态/耗时；
     - 展开行：stdout/stderr 分区、等宽、截断/超时提示、copy。
  2. 在 `main.ts` 注册：
     ```text
     ctx.slots.inject('tool.call.toolview', () =>
       ctx.slots.register({ name: 'tool.call.toolview', key: 'at_terminal_run_remote_command', locale: NS }, AtTerminalCommandRow)
     )
     ```
  3. 样式写在 `styles.ts`（`.att-tool-*`），沿用 UI2-05 的几何；不要 import `ui-primitives`。
  4. 先只做一个工具；SFTP 工具卡另开迭代。
- **DoD**：
  - 成功/失败/超时/截断四种结果都有清晰展示；
  - 解析失败回退不空白、不抛错；
  - 折叠默认、展开有 `aria-expanded`/键盘；
  - 不改变工具本身的执行与审批行为。
- **测试/验证**：纯解析模型单测 + `client-bundle.test.ts` 渲染 smoke；真机对话里看一条真实命令。
- **风险/回滚**：
  - block 结构是宿主契约，可能随版本变；解析必须容错，失败回退；
  - 注册 key 会替换通用行；先灰度一个工具，出问题可移除注册即恢复。

## 6. 风险与不做清单

### 6.1 风险

1. **`keepMounted` 不可用**：已有失败记录与测试断言（`test/dsh/client-bundle.test.ts:1133`）。UI2-03 必须走 store，不要重复试验。
2. **`styles.ts` 大面积改动的回归面**：分 PR、先 380/480 两档、双主题走查；`verify:dsh` 第 9 项必须保持 9/9。
3. **`--ds-font-family-code` 不在门禁允许的桥接变量里**：不要塞进 `TOKEN_BRIDGE`（第 9 项要求 `var(--dsw-`），在 `LAYOUT_CSS` 直接覆盖代码区域字体。
4. **guide icon 的 26px 描边**：不要直接放大 16px 图标；用独立 26px artwork，否则描边视觉过粗。
5. **`tool.call.toolview` 的 block 形状**：宿主契约可能变；解析必须容错，失败回退，先灰度一个工具。
6. **HUD 结构与拖拽**：语义改动时保留 pointer handler；先改 markup/CSS，再改交互。
7. **视觉验证依赖用户**：本计划没有浏览器控制；CSS 文本/单测只能证明规则存在，不能证明「好看」。每个视觉里程碑必须由用户在真实 dsh 里走查。
8. **共享 `webview/**`**：本计划默认不改；若某任务必须改，先单独评估 base 变体红线，不要夹带。

### 6.2 不做清单

| 不做 | 原因 | 替代 |
|---|---|---|
| import `@deepseek-ai/dsh-client-ui-*` | 官方禁止，且会让 slot 变空白 | 复制几何/行为，自有 `att-` 类 |
| 用 `workspace.toast` 发自定义 toast | key 是固定业务表 | 面板内 notice，或 `shell.overlay` 自绘 |
| 加第二个 guide entry 来放监控 | 会破坏「唯一 entry = 资产默认页」 | 工具栏/行菜单/tab menu |
| `keepMounted` 保状态 | 曾导致面板闪白，测试已断言 absence | `tabState` store |
| 持久化 password / 编辑器 buffer | 安全与过期风险 | 只持久化非敏感字段/展开路径 |
| 伪造 Test Connection / Browse 按钮 | 无对应 RPC，按钮会「点了没反应」 | 保持现状；另立 RPC 任务 |
| 直接改 `webview/**` 做 DSH 视觉 | base 变体共用 | `styles.ts` 覆盖层 |
