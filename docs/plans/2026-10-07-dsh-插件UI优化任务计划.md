**实测数据**（背景 `#101820`）：

| 颜色 | 校正前 | 校正后 | 说明 |
|---|---|---|---|

**键位不是字符串**——宿主读 `{ code: 'Digit1', modifiers: ['primary','alt'] }`（`KeyboardEvent.code`），`primary` 在 macOS 展开为 `meta`、其它平台为 `control`。写 `'Mod+P'` 会被 `Unsupported shortcut code` 拒绝。**「不绑定」= 从 `defaults` 省略该平台**（官方 files/terminal 同样省略 `web:linux`）；写了会**直接 throw** 导致插件加载失败，因为 Linux Web 只放行三个键且已被官方占满。

键位选择经过**官方校验函数实测**（从包里抽出 `normalizeBinding`/`isWebBindingAllowed`/`bindingIssue` 跑冲突检测），`Digit1/2/3 + [primary,alt]` 五平台全过且与官方零重叠。

**通过点击 nav 按钮切页而非 `setMode`**：`mode` 是 `body.ts` 里的 React state，无服务发布；`changeMode` 还做两件事（latch 首次 SFTP 访问 + 触发 reload），裸 `setMode` 会跳过。已在目标页 / 表单打开中 → 静默空操作；手势无面板焦点 → 交还浏览器不猜。

`dsh.package.json` 加 `"inject": ["@deepseek-ai/dsh-client-shortcuts"]`——**已从 asar 官方 `sidebar-files/package.json` 证实该包名确实写在 `inject` 里**。用 `inject` 而非 `external` 的理由：官方 `ui-plugin.md` 说 `external` 给「runtime imports」（bundle 里真 import 的），我们一个包都没 import。

#### UI-14 六枚自绘图标（新建 `client/icons/`）

file / folder 的几何、warningTriangle、refresh 的弧**从官方 primitive 抄录**（给出 `index.js` 行号），类名与静态色替换为 `currentColor` / `--dsw-alias-*`。**一个文件 + `strokeWidth` 参数**而非两份文件——`Medium` 定义为「同一几何 1.3px」，两份会漂移。`#[0-9a-f]{3,8}` 零命中。

几何取舍：警告三角**圆角**（官方如此）；server 画**双层机架**（单框加横线读成减号）；refresh **弧不闭合**（闭合环读成"录制中"）。全部 `aria-hidden`（可访问名归控件不归字形）。

#### UI-15 滚动条 / UI-17 断点 / UI-16 空态出路

滚动条：`.att-menu` 重绑 l2（从 `dsh-client-ui-theme/lib/client.js:1157` 实读官方约定，body 上是 l1、高层级表面在自己容器上绑 l2）。

断点用 **`@container` 而非 `@media`**——变窄的是侧栏不是窗口。**且刻意放在 `.att-page` 而非 `.att-root`**：`container-type` 隐含 layout containment，会让元素成为定位后代的包含块，而 `.att-menu` 是 `position: fixed` 用视口坐标——放 root 上菜单会被面板偏移拖走。`480px` 是**我们自己的判断**（从服务器列表工具栏量出），注释已标注为待实测的首次猜测，未编造官方式数值。

空态出路：「无终端」加「去终端页」、`disconnected` 加「重连」——复用已有 key（`mode.terminal`、`terminal.reconnect`），**零新增 i18n key**。

## 6. 未验证项与风险（诚实登记）

1. **浅色模式从未真机看过** —— 全部"浅色风险"由代码推导（32 个 fallback 全深色值）。UI-08v 之前不能宣称主题适配完成。
2. **`web-styling.zh.md` 取不到** —— 被官方 README 反复引用为"权威样式参考"，但 `/dsh/docs/` 在本机 asar 中**为空**（0 文件），全 asar 搜索零命中。**本计划不引用其数值**；`Button` 的 H36/R12 来自 `ui-primitives` README 正文，可信度次一级。
3. **UI-08 会碰 base 变体共用区** —— `webview/terminal/theme.ts` 被 `test/webview/TerminalTheme.test.ts`（110 行）守着。这是本计划**唯一**触及硬红线的任务，W2 波次独占该文件，且必须在 U2 出口跑红线五文件。
4. **官方 403 token 仅抽样比对** —— 逐一验证了 at-terminal 实际用到的 11 个；UI-09 扩充时需对新增 token 全量比对。
5. **快捷键的平台默认值** —— macOS/Windows 用官方服务默认值，**Linux 默认不绑定**；具体键位以运行时 `shortcuts` 服务为准，计划里的 `mod+P` 只是形态示例。
6. **本计划未修改任何生产代码** —— 全部为计划编排。基线门禁数字取自 2026-10-07 实跑，若期间有提交须重跑。
