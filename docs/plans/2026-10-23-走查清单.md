前提：**三台都连着**时，写类/执行类必须显式 `serverId`。

| # | 操作 | 期望 |
|---|---|---|
| 4.1 | `at_terminal_run_remote_command` 打 **99.90（full）**，命令 `id` | **不弹窗**，直接 `exit 0` |
| 4.2 | 同上打 **99.92（policy）**，命令 `id` | **不弹窗**（策略判定安全），`exit 0` |
| 4.3 | 同上打 **99.94（none）**，命令 `id` | **弹窗**「Run remote command on 99.94 …」，点「允许一次」后执行；审计落 `user_approved` |
| 4.4 | `at_terminal_sftp_write_file` 打 **99.90** 写 `/tmp/x1.txt` | **不弹窗**，`Wrote N bytes` |
| 4.5 | 同上打 **99.92** 写 `/tmp/x2.txt` | 弹窗带两个选项：`Allow Once` / `Allow This Folder For 15 Minutes` |
| 4.6 | 选 **Allow This Folder For 15 Minutes** → 提交，然后**同目录再写** `/tmp/x3.txt` | 第二次**不弹窗**（目录授权生效） |
| 4.7 | 写 **99.92** 的 `/etc/x.conf`（敏感路径 + 越界） | 弹窗**只给** `拒绝 / 允许一次`（没有目录授权），文案含两行 WARNING（working directory + sensitive path） |

## 11. 已知限制（**不要当 bug 报**）

| 现象 | 为什么 |
|---|---|
| `terminal_signal` 直接报错 | `ssh2` 没有 pty 信号通道；报错文案给了两条可行路径。谎报 `delivered:true` 才是错的 |
| `terminal_*` 里看不到颜色 | 有意为之：这个后端没有 xterm 渲染器，剥掉转义是为了不给模型付 token |
| 会话头部监控按钮的 hover 效果在「从未打开过面板」时不出现 | 该按钮用内联样式兜底（否则会把样式 chunk 拖回启动路径）；打开过一次面板后 hover 恢复 |
| 三台都连着时写类不传 `serverId` 会报错 | S5-04 的规则：**拒绝猜测**，不是回归 |
| 面板首次打开比之前慢一点点（约几毫秒） | 样式 chunk 在首帧前取；换来的是启动少下 93 KB |
| `at_terminal_sftp_list_directory` 的 `~user` 不展开 | 要读 `/etc/passwd`，是另一个问题；`~` 与 `~/x` 已展开 |
